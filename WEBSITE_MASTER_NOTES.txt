[ 2. เทคโนโลยีและเครื่องมือที่ใช้พัฒนา (Tech Stack) ]
--------------------------------------------------------------------------------
• Framework: Next.js 16 (App Router) + React 19 + TypeScript
• Styling: Tailwind CSS v4 + PostCSS
• Animation & Effects: Framer Motion, Lucide React Icons
• Payment UI: PromptPay QR Code (promptpay-qr, qrcode.react)
• Database & Auth: Supabase (@supabase/ssr, @supabase/supabase-js)
• AI Engine: Google Gemini API (Gemini 2.5 Flash / 3.8 Flash)
• Webhook & Integrations: LINE Messaging API, Facebook Graph API, Instagram API, Telegram Bot, Google Apps Script (GAS)

[ 4. รายการ Environment Variables สำคัญ (.env.local) ]
--------------------------------------------------------------------------------
(ไฟล์จริงอยู่ที่ C:\iAonDev2026\.env.local - สำรองเก็บแยกไว้ อย่าอัปโหลดขึ้นสาธารณะ)
• NEXT_PUBLIC_SITE_URL             = https://www.aiaon.tech
• NEXT_PUBLIC_SUPABASE_URL         = (URL โปรเจกต์ Supabase)
• NEXT_PUBLIC_SUPABASE_ANON_KEY    = (Anon Public Key ของ Supabase)
• NEXT_PUBLIC_ADMIN_EMAIL          = (อีเมลแอดมินสำหรับจัดการระบบ)
• GEMINI_API_KEY                   = (API Key สำหรับระบบผู้ช่วยอัจฉริยะ)
• LINE_CHANNEL_ACCESS_TOKEN        = (สำหรับ LINE Bot / การส่งงาน)
• LINE_CHANNEL_SECRET              = (รหัสความปลอดภัย LINE Webhook)
• FB_PAGE_ACCESS_TOKEN & IG        = (ระบบเชื่อมต่อเพจและอินสตาแกรม)
• TELEGRAM_BOT_TOKEN & CHAT_ID     = (ระบบแจ้งเตือนเข้า Telegram อัตโนมัติ)
• DELIVERY_SIGNING_SECRET          = (รหัสเข้ารหัสลิงก์ส่งมอบสินค้าดิจิทัล)


[ 5. คำสั่งที่ใช้ประจำใน Terminal (Cheat Sheet Commands) ]
--------------------------------------------------------------------------------
เข้าโฟลเดอร์โปรเจกต์:
  cd C:\iAonDev2026

เปิดทดสอบบนเครื่อง Local (เข้าดูที่ http://localhost:3000):
  npm run dev

ทดสอบ Build โค้ดเสมือนจริงก่อน Deploy:
  npm run build

ขั้นตอนนำโค้ดขึ้นระบบจริง (Deploy สู่ aiaon.tech):
  git add .
  git commit -m "อัปเดตฟีเจอร์ใหม่"
  git push origin main
  (ระบบ Vercel จะดึงไปสร้างเว็บจริงให้เองอัตโนมัติภายใน 1-2 นาที)


[ 6. โครงสร้างไฟล์ใน C:\iAonDev2026 ที่ควรรู้ ]
--------------------------------------------------------------------------------
• src/app/          -> ที่อยู่ของหน้าเว็บทุกหน้าและ API Endpoints
• src/components/   -> คอมโพเนนต์ UI, การ์ด 3D Mockup, โมดอล, แถบเมนู
• public/           -> ที่เก็บรูปภาพ ไอคอน โลโก้ และไฟล์เอกสารที่ให้ดาวน์โหลดผ่านเว็บ
• supabase.sql      -> โค้ดฐานข้อมูลและตารางสินค้า/คำสั่งซื้อ
• package.json      -> รายการไลบรารีและปลั๊กอินทั้งหมดของเว็บ

--------------------------------------------------------------------------------
